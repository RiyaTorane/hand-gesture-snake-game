\# 🐍 Hand Gesture Snake Game



A Python-based Snake game controlled using \*\*real-time hand gestures\*\* through a webcam.



The project uses computer vision to detect the player's hand and allows the Snake to be controlled without using a keyboard.



\## ✨ Features



\* Real-time hand gesture detection

\* Webcam-based Snake controls

\* Snake game built with Pygame

\* Hand tracking using MediaPipe

\* Real-time video processing using OpenCV

\* Score tracking

\* Game-over detection



\## 🛠️ Technologies Used



\* Python

\* OpenCV

\* MediaPipe

\* Pygame

\## ⚙️ Installation



Clone the repository:



```bash

git clone https://github.com/YOUR-USERNAME/hand-gesture-snake-game.git

```



Go into the project folder:



```bash

cd hand-gesture-snake-game

```



Install the required libraries:



```bash

pip install -r requirements.txt

```



\## ▶️ How to Run



Run the following command:



```bash

python snake\_hand\_game.py

```



Make sure your computer has a working webcam.



\## 🎮 Controls



The Snake is controlled using hand gestures detected through the webcam.



Show your hand clearly in front of the camera and move it in the desired direction.



\## 📌 Project Purpose



This project demonstrates the use of \*\*computer vision and hand tracking\*\* to create an interactive game without traditional keyboard controls.
